# Sistem Informasi KSP Maju Bersama

Tugas Web Dasar pertemuan 6 (Frame dan CSS Dasar).

Halaman:
- index.html - beranda
- login.html - halaman login
- dashboard.html - dashboard
- anggota.html - data anggota
- form-anggota.html - form pendaftaran anggota
- simpanan.html - simpanan
- pinjaman.html - pinjaman
- angsuran.html - angsuran
- laporan.html - laporan dan SHU
- tentang.html - profil koperasi

Cara membuka: buka file index.html di browser, klik Masuk, lalu klik tombol Masuk di halaman login untuk ke dashboard.
